The Problem vs The Solution

Understanding why Google Antigravity fails to connect and how this patch resolves it.

The Problem

Connection Failures

  • Antigravity requires direct access to Google servers for sign-in and AI features.
  • Fails completely behind corporate HTTP proxies or restricted/sanctioned networks.
  • Child processes like language_server.exe bypass system-wide proxy settings.
  • Common error: 'failed to make code assist backend request'.
[Error - 09:42:01] language_server.exe: connection refused
[Error - 09:42:02] Authentication failed: unable to reach accounts.google.com
[Warning] failed to make code assist backend request
The Solution

Process Interception

  • DLL injection intercepts network calls at the operating system socket level.
  • Forces all child processes (language_server.exe, node.exe) through your proxy.
  • Automated config script sets env variables, VS Code, and GUI settings.
  • Fully open source, transparent, telemetry-free, and easily reversible.
[Info - 09:45:12] version.dll: Intercepting network traffic...
[Info - 09:45:13] Tunnel established: accounts.google.com -> 127.0.0.1:12334
[Success] Antigravity authentication successful!

Installation Guide

Follow these three simple steps to patch your Google Antigravity installation.

1

Configure Your Proxy

Open Antigravity 2/antigravity-proxy-patch/proxy.settings.txt in any text editor and configure your HTTP proxy host and port.

proxy.settings.txt 
HOST=127.0.0.1
PORT=12334
TYPE=http
Proxy Tool HOST PORT Notes
Clash 127.0.0.1 7890 Default HTTP proxy port
V2RayN 127.0.0.1 10809 HTTP proxy (not SOCKS)
Shadowsocks 127.0.0.1 1080 With HTTP proxy plugin
Corporate Proxy Your Corp IP Your Port Ask your IT department
Squid 127.0.0.1 3128 Default Squid port
2

Run the Installer

Double-click Antigravity 2/antigravity-proxy-patch/Install-Patch.bat to automatically apply all patches, edit VS Code user settings, and set env variables.

PowerShell (Option B) 
.\Install-Patch.ps1 -AntigravityDir "C:\Program Files\Antigravity"

Run the Installer: Advanced Users: You can run Install-Patch.ps1 in PowerShell with custom flags like -SkipEnv or -SkipUserSettings.

3

Launch Antigravity

Always start Antigravity using the newly created batch file in the install folder.

Launcher Path 
%LOCALAPPDATA%\Programs\Antigravity\Antigravity-with-proxy.bat

Important: Do NOT use the regular Start Menu shortcut, as it won't load the proxy injector DLL.
